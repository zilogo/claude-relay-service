## 1. 概述

本文档记录了 `zyp-pay-dev` 分支从 2025年11月17日 到 2025年12月29日 期间的所有重要变更。该分支主要聚焦于以下几个核心方向：

1. **用户系统完善**: 实现了完整的用户注册、邮箱验证、密码找回功能
2. **支付系统集成**: 集成了 ZPAY 和 Stripe 微信支付，实现余额管理和在线充值
3. **营销功能**: 添加了邀请返利、限时活动、首充优惠等营销功能
4. **第三方集成**: 集成钉钉机器人充值功能
5. **前端体验**: 完善了用户界面，集成独立的 frontpage，优化UI/UX
6. **性能和安全**: 修复重大安全漏洞，优化用户管理页面性能
